# Permutation

permutation relates to the act of **arranging** all the members of a set into some sequence or order.

Ex:ABC
A B C
A C B
B A C
B C A
C A B
C B A

permutations = 3 _ 2 _ 1;

HELO => 4 _ 3 _ 2 \* 1 = 4! = 24

If it is digits , for eg: 123 => 3 _ 3 _ 3 = 3^3 = 27
